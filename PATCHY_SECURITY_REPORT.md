3. Introduced bcrypt to hash passwords with a configurable salt rounds; removed plaintext storage.

**Security Notes:** - Ensure your .env file is not checked into version control and is stored securely.

- Monitor bcrypt performance; adjust BCRYPT_SALT_ROUNDS as needed to balance security and performance.
